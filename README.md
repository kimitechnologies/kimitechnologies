## About

Kimi Technologies is an information technology company and an independent media company, founded in 2023 and run by the same people.

The studio builds web software. The newsroom reports on artificial intelligence and robotics. Because the same team does both, the code and the writing are held to one standard: no black boxes, no unnecessary dependencies, and nothing collected that does not need to be collected.

## Founder

Kimi Technologies was founded in 2023 by [ItsNobodyX](https://github.com/ItsNobodyX), who continues to run the company and maintain its open-source projects.

### Engineering principles

- **Client-side first.** If a task can run in the browser, it runs in the browser. User files never leave the device.
- **No tracking.** No analytics, no third-party scripts, no telemetry of any kind.
- **Boring technology.** Static files, semantic HTML and as little JavaScript as the job allows. It loads faster, breaks less, and anyone can maintain it later.
- **Accessible by default.** Keyboard navigable, responsive at every breakpoint, and readable at any text size.
- **MIT, without exceptions.** Fork it, modify it, ship it inside your own product.

## The newsroom

Independent coverage of artificial intelligence, robotics and hardware, and the industry and policy around them — with a particular interest in what Indian technology policy means for teams building here.

Reporting is written from primary sources: papers, filings, documentation and people who were in the room. No sponsored posts, no rewritten press releases, and no coverage traded for access. Corrections are made in the open.

Coverage is published on [LinkedIn](https://www.linkedin.com/company/kimitechnologies/).

## Contributing

Issues and pull requests are welcome on any public repository.

- Keep the client-side constraint: no server-side processing, no data collection.
- Match the existing style, and keep dependencies out unless there is a clear reason for one.
- For anything larger than a bug fix, open an issue first so the approach can be agreed before the work.
- Security reports should go to **official.kimitech@gmail.com** & **connect.kimitech@gmail.com** with `security` in the subject line, not to the public issue tracker.
